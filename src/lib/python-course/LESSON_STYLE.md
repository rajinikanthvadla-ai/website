# Python course lesson writing rules

Own voice. Keep lessons short, clear, and practical for AI / ML beginners.

## Structure
1. **Basics first** - one idea per section, short text, tiny runnable example
2. **Then AI / ML examples** - 1 or 2 only, after the student already understands the basics
3. No walls of text. No long tables. No huge data dumps.

## Section body
- 2 to 5 short sentences or a small bullet list
- Plain English a beginner can read once
- Optional one line: `Common mistake: ...`
- No em dashes. Use "-" or rewrite.

## basicCode
- 2 to 8 complete lines
- Must run as-is (balanced brackets)
- Comments only when they teach (`# int`)

## Examples (AI / ML block)
- Title starts with `AI / ML:`
- `note` = one short sentence
- `aiMl` = one short sentence
- `why` / `analogy` optional one sentence or omit
- Code under ~12 lines

## Titles
- Prefer clear names: "Python Numbers", "Python Lists", "Python If Else"
- Keep existing slugs unchanged
